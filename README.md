# فن الكسل // Productivity_Not_Found_404

> موقع بسيط لكل واحد بيفضل ميعملش حاجة.

موقع ساخر بواجهة على شكل تيرمينال، بيقدّم أدوات وهمية (وبعضها حقيقي) لكل حد بيؤمن إن الكسل مهارة مش عيب. مبني بالكامل بـ HTML, CSS, JavaScript من غير أي framework أو build step.

**Live:** [found.vercel.app](https://found.vercel.app)

---

## المميزات

- **مؤشر الكسل العالمي** — بار متحرك بيهتز بشكل عشوائي عشان يدي إحساس إحصائية حقيقية.
- **مقالات برمجية للكسالى** — تدوينات قصيرة بأسلوب ساخر عن فن عدم الإنتاجية.
- **محاكي تيرمينال** — بيقبل أوامر (`sleep`, `work`, `coffee`) ويرد عليها برسائل جاهزة.
- **مولّد أعذار الديفلوبر الكسول** — زرار بيطلّع عذر عشوائي (Subject + Reason) لأي تاسك متأخر.
- **حاسبة توقيت النوم المثالي** — بتحسب أنسب مواعيد للنوم بناءً على معاد الصحيان، بالاعتماد على دورات نوم 90 دقيقة.
- **حكمة برمجة وكسل عشوائية** — زرار بيديك اقتباس مختلف كل مرة.
- **عدّاد زوار حقيقي** — بيزوّد فعلياً مع كل تحميل صفحة (مش رقم وهمي)، عن طريق API خارجي مجاني.
- **حفظ النتائج كصورة** — أي عذر أو حكمة أو خطة نوم أو تذكير تقدر تحفظه كصورة PNG على جهازك.
- **بوب أب "تأجيل القراءة"** — تجربة إغلاق ساخرة بأسلوب شاشة تيرمينال بتقفل النظام.
- **إنجازات وبادجات** — توست بيظهر أول مرة تستخدم فيها كل أداة (أول عذر، أول أمر تيرمينال، إلخ).
- **تصميم متجاوب بالكامل** — متبني من الأول للموبايل، مع عناصر تحكم مخصصة (Custom Selects) بدل عناصر الفورم الافتراضية اللي بتختلف من متصفح لمتصفح.
- **دعم `prefers-reduced-motion`** — بيوقف كل الأنيميشن للمستخدمين اللي فعّلين تقليل الحركة.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 | البنية، ملف واحد بدون build step |
| CSS3 (Custom Properties) | التصميم بالكامل، Dark theme ثابت |
| Vanilla JavaScript | كل التفاعلات، من غير أي framework |
| [Google Fonts](https://fonts.google.com) | خط Cairo للنصوص العربية، Fira Code للتيرمينال |
| [html2canvas](https://html2canvas.hertzen.com/) | تحويل أي بلوك في الصفحة لصورة PNG قابلة للتحميل |
| [CountAPI](https://countapi.mileshilliard.com/) | عدّاد الزوار الحقيقي بدون تسجيل أو Backend خاص |
| [Vercel](https://vercel.com) | الاستضافة والنشر |

## هيكل المشروع

```
.
├── index.html   # الموقع بالكامل: HTML + CSS + JS في ملف واحد
└── README.md
```

الموقع Static بالكامل — مفيش Backend، مفيش Build Step، مفيش Dependencies تتنزل. تفتح الملف في المتصفح ويشتغل زي ما هو.

## التشغيل محلياً

مش محتاج أي تثبيت، افتح الملف مباشرة:

```bash
open index.html
```

أو شغّل سيرفر بسيط لو عايز الـ features اللي محتاجة اتصال إنترنت (زي العدّاد وحفظ الصور) تشتغل بشكل طبيعي:

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000`.
